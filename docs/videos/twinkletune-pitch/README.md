# TwinkleTune · Pitch

> **Runtime:** 0:30 · **Audience:** families with young singers · **Captions:** none

**Video:** [twinkletune-pitch.mp4](twinkletune-pitch.mp4) · [Transcript](script.md)

A short, upbeat pitch that invites kids and their grown-ups to try TwinkleTune and have fun
testing their singing. Every phone on screen is a real screenshot of the running app (Vite dev
build, driven by Playwright with a fake microphone that sings *Twinkle Twinkle Little Star* and
glides up the Find My Voice ladder).
