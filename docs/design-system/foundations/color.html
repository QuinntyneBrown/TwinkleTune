Color

A sky studio for little singers: soft brand blues, gentle pink and reward gold, every text pair checked live in both themes. Colour never carries meaning alone.

Overview

TwinkleTune's colour lives in three tiers. Primitives (--palette-*) are the raw ramps and are never read by a component. Semantic roles (--color-*, --gradient-*) say what a colour is for, and are the only tier a theme overrides. Component tokens (--btn-bg, --pill-fg, --alert-bg) live in components.css and alias a role.

  • Blue is the brand and the one big action. The brand blue (--palette-sky-400) is too light for white words, so buttons use a deeper accent and the brand blue paints fills and rings.
  • Pink is the gentle voice: nudges, the soft second choice, the current lyric word.
  • Gold means a sparkle was earned: stars, landed notes, the reward button.
  • There is no "wrong" colour for children. The rose danger family exists only for grown-ups' destructive confirms and validation in the Grown-Ups Corner. A missed note is never red; silence is never a colour.

The shipped app is light (the sky studio). Dark (the studio at night) applies with data-theme="dark" or the OS preference; see Theming for the mechanics.

Adding a brand theme

A theme is a block that re-points semantic roles at different primitives. Components never change. To add one (say a holiday "snow studio" or a school partner's colours):

  1. Add primitives to tokens.css as a new ramp (--palette-snow-50 … 900). Primitives are the only place a raw value may appear.
  2. Override roles under a selector: [data-theme="snow"] { --color-accent: var(--palette-snow-700); --color-accent-graphic: var(--palette-snow-400); … }. Override the whole background, foreground, border and accent groups together; leave gold alone so rewards stay recognisable.
  3. Repeat the composite tokens (every --gradient-* and --shadow-focus) inside the block, as the dark theme does, so nested themes recompute them.
  4. Run the contrast check (scripts/check_contrast.py) against contrast-pairs.json for the new theme. Every pair on this page must still pass; the accent must carry its label at 4.5:1 and stand off the canvas at 3:1.
  5. Check the encouragement test: no role may make a missed note or silence look like failure. Danger stays grown-ups only.
[data-theme="snow"] {
  --color-bg-canvas: var(--palette-snow-100);
  --color-accent: var(--palette-snow-700);        /* label 4.5:1 or better */
  --color-accent-edge: var(--palette-snow-900);
  --color-accent-graphic: var(--palette-snow-400);
  --color-focus-ring: var(--palette-snow-700);
  --gradient-sky: linear-gradient(180deg, var(--color-decor-aqua) 0%, var(--color-decor-pale) 40%, var(--color-decor-haze) 68%, var(--color-gentle-bg) 100%);
}

Usage

  • Read roles, never primitives. color: var(--color-fg-accent), not var(--palette-sky-700). Never write a hex value in a component.
  • Text on blue is --color-fg-on-accent on --color-accent. Brand blue (--color-accent-graphic) is for fills, rings and the equaliser, never behind words.
  • One blue and one gold action per screen. Colour sets the hierarchy; a second blue button competes with the first.
  • Gold is earned. Use reward tokens only for sparkles, stars, landed notes and celebration, never for decoration or warnings.
  • Danger is for grown-ups. --color-danger-* appears only in the Grown-Ups Corner, family-server managers and their confirms.
  • Never colour alone. Selected chips also flip to a filled shape, today's day disc has aria-current and text, the current lyric word is also bolder, and every status has an icon and words.
  • Decor tokens are for the sky. --color-decor-* paint gradients, clouds and staff lines; they fail as text and edges by design.
