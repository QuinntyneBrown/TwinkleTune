Typography

Big, round and friendly. Baloo 2 sings the headings and buttons; Nunito, set bold, speaks every sentence. Nothing a child reads is smaller than 12px.

Overview

Type in TwinkleTune is part of the toy. Headings are short and chunky, body copy is bold so it reads at arm's length on a tablet propped on a music stand, and there are very few words per screen. Two families, self-hosted from mocks/assets/fonts with metric-matched fallbacks so a missing webfont never reflows a screen, and no third-party font requests (privacy first).

  • Baloo 2 (--font-family-display): screen titles, dialog titles, buttons, the wordmark, the countdown and the tuner note.
  • Nunito (--font-family-sans): everything else. Bold (700) is the default body weight; that weight is the product voice.
  • Monospace (--font-family-mono): grown-up surfaces only, such as song note data in the song editor and code on these pages.

Components set type with the role shorthands (font: var(--text-h2)) rather than picking size, weight and family separately.

Measure and responsive type

  • Child screens are one 470px column (--layout-screen-max), which keeps bold 16px body text near 45 characters per line. Twinkle's bubbles are shorter still: one or two sentences.
  • Grown-up and docs prose caps at --layout-measure (65ch).
  • No viewport units. The scale is fixed rem steps, so type follows the reader's text size and zoom. Nothing switches size at a breakpoint; the layout changes instead (see Layout).
  • Never truncate a child's text. Song titles and button labels wrap; a label that wraps at 360px is too long, so shorten the words.
  • Balance headings. Screen and dialog titles use text-wrap: balance so a two-line title does not leave one word alone.

Usage

  • Set type with a role: font: var(--text-body). Reach for a raw --font-size-* only for one-off display moments (countdown, tuner note) that have no role.
  • Body copy is bold Nunito. Do not drop a child-facing sentence to regular weight to make it look "lighter"; it becomes harder to read.
  • Baloo 2 is for short display text: titles, buttons, numerals. Never set a paragraph in it.
  • All caps only with --letter-spacing-wide and only for 1–3 word labels (SINGING NOW ⭐, THIS WEEK). Never for sentences; early readers decode lower case more easily.
  • Emoji inherit the text size. One emoji per label at most, at the end, and decorative ones are aria-hidden="true" (see Iconography).
  • Numbers that count up (sparkles, scores) use font-variant-numeric: tabular-nums so they do not jitter.

Accessibility

The 12px floor (D10)

The mocks used 10.5–11.5px text for pills, weekday letters, the stage label, the profile tag and the ladder label. All of it is raised to --font-size-xs (12px), set extrabold or black. Nothing a child or grown-up reads may be smaller.

Zoom and text spacing

  • All sizes are rem, so 200% text zoom works without loss (WCAG 1.4.4). Containers grow with their text; no fixed heights around words.
  • Layouts survive WCAG 1.4.12 text-spacing overrides (line height 1.5, paragraph spacing 2em, letter spacing 0.12em, word spacing 0.16em).
  • Contrast is measured per pair on Color. Large text (24px+, or 18.66px+ bold) needs only 3:1, but TwinkleTune holds every text role to 4.5:1 regardless.

Readers and early readers

Many singers cannot read yet. Twinkle's words are short, pictures (emoji, art) sit beside words, and the one big action is recognisable by colour and position as well as its label. Text is still always present: it is the accessible name.
