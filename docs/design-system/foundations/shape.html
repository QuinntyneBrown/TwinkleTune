Foundation

Shape

Nothing in TwinkleTune has a sharp corner. Six radii from 4px to a full pill, four border widths, and a set of fixed dimensions for Twinkle, avatars, marks and controls.

WCAG 2.2 AATokens --radius-* --border-width-* --size-*Status: stable

Overview

Round shapes feel safe and toy-like, and they echo Twinkle herself. The mocks used fourteen different radii; they collapse to six (D12). Borders are rare: shape and colour separate most things, and borders appear where a control's edge must be seen (fields, dashed add cards, rings around the chosen avatar).

This page also owns the dimensions (--size-*): the fixed sizes of art, marks and controls that are not spacing, such as Twinkle at 110px or a progress track at 16px.

Which radius for which size

The bigger the thing, the bigger the radius, so every corner looks equally soft. Interactive pieces a child presses are pills wherever their shape allows.

TokenSize of the thingUsed by
--radius-xsTiny detailsSpeech-bubble tail, tuner needle, swatch chips
--radius-smSmall marksFocus outline corners, small marks, inline code
--radius-mdControls up to ~56pxFields, number keys, manager rows, room-code tiles
--radius-lgRows and medium tilesSong rows, home tiles, bubbles, badges, alerts, large inputs
--radius-xlCards and panels.card, .modal, pitch stage, hero tile
--radius-fullAnything pill or roundToy buttons, chips, pills, tracks, toasts, bottom nav, avatars

Nested corners: an inner element's radius is the outer radius minus the padding between them, rounded to the nearest step. A 32px card with 20px padding holds 16px (or smaller) children, not another 32px box.

Border widths

Hairline 1px, thin 2px, thick 3px, heavy 4px ring, and the dashed add-card edge.
TokenWidthUsed by

Control edges use --color-border-strong so they meet 3:1 (D07); dashed add cards keep the decorative --color-border-decor because their words and button carry the meaning. Colours are on Color.

Usage

  • Pick the radius from the table by the element's size. Never write a raw radius, and never mix two radii on one element's corners.
  • Anything a child taps that can be a pill, is a pill. Square-ish keys (the parent gate's number pad) use --radius-md.
  • Circles use --radius-full on a square box (--size-avatar × --size-avatar), not 50% on a rectangle.
  • Use the thinnest border that does the job. Most surfaces need none: a white card on the sky is already separated by colour and shadow.
  • Use a --size-* token for any fixed art or mark size so Twinkle, avatars and marks stay consistent across screens.
