Slider

The native range input in the accent colour, always with its value written beside it. The Grown-Ups Corner uses it for the mic timing offset, which saves as it moves.

Overview

Use a slider when a grown-up nudges a number within a range and the exact value matters less than the feel: Mic timing offset, from −300 to +300 ms in 10 ms steps, in the Grown-Ups Corner. "If cheers feel late, nudge this." The value is always shown as text beside the slider, and the setting applies as it moves.

  • In a setting row (the mock): label and hint on the left, slider in the middle, value on the right.
  • Stacked: label above, slider and value below, with optional tick marks. For forms where several settings line up.

If the exact number matters (a song's tempo), use a number text field. Children never use a slider: dragging a thin thumb is hard for small hands. The mic timing offset belongs to the device, not the singer, which is one reason it lives behind the parent gate.

Anatomy

  1. Label and hintThe setting's name in extra-bold 14px, a <small> hint in --color-fg-muted under it.
  2. TrackDrawn by the browser, tinted by accent-color: var(--color-accent): the filled part is accent, the rest the browser's neutral.
  3. ThumbBrowser-drawn in the accent colour. The control row is at least 44px tall.
  4. Value<output> with the number and unit (40 ms), bold. The slider's position is never the only way to read it.

Stacked with ticks

0 ms means no change. If cheers feel late, nudge it a little and sing again.

A tick at zero helps a grown-up find "no change". The hint says what zero means.

Sizes

One size: full width of its slot, browser-drawn thumb, 44px minimum row height.

States

The track and thumb are drawn by the browser, so hover and pressed are the browser's own. Focus uses the shared ring on :focus-visible; it cannot be forced on a static page, so the Focus column holds a live slider: tab to it.

Both themes

  • Disabled is 55% opaque with a not-allowed cursor. The mic offset is never disabled; it works without a family server and without a microphone permission.
  • No invalid state: the range itself prevents a bad value.

Responsive behaviour

  • In a setting row the slider takes the remaining space (flex: 1) between label and value. At 320px inside a 340px dialog that leaves it about 100px; if the label wraps further, move to the stacked variant.
  • The value keeps its width so the slider does not jump as the number changes; reserve room for the longest value (−300 ms).
  • Stacked sliders are full width of the form column.

Theming

One token: accent-color: var(--color-accent). The browser picks the unfilled track and the thumb's outline to contrast with it, so the slider follows the theme without custom track CSS. Set color-scheme on the theme root so the unfilled track is dark in the night studio.

Accessibility

Role and pattern

Native <input type="range">, which has the slider role and value built in (APG Slider). Add aria-valuetext when the number alone is unclear: 40 milliseconds reads better than "40", and minus 120 milliseconds better than "-120".

Keyboard

KeyAction
Tab / Shift+TabMoves to and from the slider.
→ / ↑Increases by one step (10 ms).
← / ↓Decreases by one step.
Page Up / Page DownLarger jumps (browser-defined, about a tenth of the range).
Home / EndLowest (−300 ms) / highest (+300 ms).

Focus

The shared ring (3px --color-focus-ring, 3px offset) around the whole control on :focus-visible.

Labelling

Tie the visible label to the slider with <label for>; the mock gives it only aria-label and leaves the visible text loose. Show the value in an <output for>, and update aria-valuetext with it.

Dragging alternative

WCAG 2.5.7: a single tap anywhere on the track moves the thumb there, and the arrow keys step it, so dragging is never required.

The unfilled track is browser-drawn and not tokenised; the value text carries the information either way.

Motion

None; the thumb follows the pointer.

Touch

The control is at least 44px tall. Keep at least 8px between the slider and the value so a thumb at the end is not mistaken for a tap on the text.

Content

  • The label names the setting; the hint says when to touch it, in the reader's words: If cheers feel late, nudge this.
  • Always show the value with its unit: 40 ms, −120 ms, 0 ms. Use a real minus sign.
  • Mark the zero point (a tick, or "0 ms means no change" in the hint) so a grown-up can always get back to where they started.

The .slider class and the stacked variant are new in the system. Drift that applies: the accent was brand blue at 2.6:1 on white and is now --color-accent (D01); focus ring --color-focus-ring (D21).
