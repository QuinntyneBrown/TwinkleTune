Avatar

A singer's face in the app: her chosen emoji, or a family photo, in a round pastel disc. It is how a child recognises herself on Home, Me, the profile picker and the duet lobby.

Overview

An avatar shows who is singing. Each Singer picks one of eight emoji (🦄 Unicorn, 🐱 Kitten, 🐸 Frog, 🦊 Fox, 🐰 Bunny, 🐼 Panda, 🦖 Dino, 🐙 Octopus) or, with a grown-up's help, a photo stored on the family server. The avatar is display only; choosing one is the avatar picker.

  • Emoji avatar (.avatar): the emoji centred on the pink-to-pale --gradient-avatar disc with a soft shadow.
  • Photo avatar (.avatar > img.avatar-photo): the photo fills and crops to the circle. It replaces the emoji when the singer has one (Mum). Photos never leave the home network; offline, the emoji shows instead.
  • Icon disc: the same disc holding a prompt emoji instead of a face, such as 🎯 on the empty-state goal card. Always decorative.

Anatomy

  1. FaceEmoji at --font-size-3xl (56px disc) or --font-size-5xl (84px disc), or a photo with object-fit: cover.
  2. DiscCircle with --gradient-avatar (gentle pink to pale sky) and --shadow-1.
  3. Rim (large only)A 4px --color-bg-surface border that lifts the large avatar off a card or the sky.

States

The avatar itself is not interactive. When it sits inside a link (Home's greeting avatar switches singer) the link takes the states and the ring. The singer's identity state is shown next to the avatar in words, never by the avatar alone.

Responsive behaviour

  • Avatars keep their size at every width (flex: 0 0 auto); text beside them wraps instead.
  • In the profile grid, each card is at least 150px wide, so a large avatar always has room; the grid adds columns rather than growing avatars.
  • Photos are cropped to the circle by object-fit: cover; upload any aspect ratio up to 2 MB (jpeg, png or webp).

Theming

The disc reads --gradient-avatar (built from --color-gentle-bg and --color-decor-pale) and --shadow-1; the large rim reads --color-bg-surface. In the night studio the rim follows the raised surface colour, so it still separates the avatar from a dark card.

Accessibility

Role and pattern

No APG widget applies. An emoji avatar that carries meaning is role="img" with an aria-label; a photo is an <img> with alt. When the singer's name is printed right beside the avatar (profile cards, duet lobby), the avatar is decorative: aria-hidden="true" or alt="", so the name is not read twice.

Keyboard

KeyAction
TabSkips a bare avatar. An avatar wrapped in a link is reached as that link.
EnterFollows the wrapping link (Home: switch singer).

Focus

The wrapping link draws the shared ring; give it border-radius: 50% so the ring follows the disc.

Labelling

Label with the singer's name, not the emoji's dictionary name: "Ada" or "Your avatar", not "unicorn face". The mocks use aria-label="Your avatar" on Home inside a link named Switch singer; the link's name is what is announced, so the inner label can be dropped (aria-hidden). In the avatar manager, where the animal is the point, the name is the animal (Unicorn).

Contrast

Name beside an avatar on a card
Profile tag beside an avatar

Emoji and photos are images, not text; the disc edge is decorative. Identity is always also given by the printed name.

Motion

The Me header avatar pops in (.pop, --duration-deliberate, spring easing). Reduced motion shows it in place.

Touch

A tappable avatar (Home greeting) is wrapped in a link at least 52px across; the 56px disc meets the child target.

Content

  • Avatar names are friendly animal names a child would say: Unicorn, Kitten, Dino.
  • Photo alt text is the singer's name only (Mum). Never describe the person's appearance.
  • One avatar per singer; there is no "default grey person". A new singer picks an emoji before she starts.
