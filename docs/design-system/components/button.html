Button

Chunky toy buttons with a solid lip underneath. They are the one big obvious action on every screen, and pressing one feels like pushing a real toy button.

Overview

Use a button when tapping it does something: starts a song, saves a singer, opens a dialog. If it only goes somewhere, it is still styled as a button on child screens (the big tile and results actions are links that look like buttons), but it is marked up as <a href>. Use a quiet link for the softer second choice, and an icon button for back, pause and settings.

  • Blue (.btn) is the one action the screen exists for: Let's sing!, Keep singing, Add singer. One per screen.
  • White (.btn-white) is an equal, calmer alternative: Sing again, Start over, Preview.
  • Pink (.btn-pink) is the gentle choice: New song, Pick another song, and the soft first step of a reset.
  • Gold (.btn-gold) celebrates: Practice the tricky part, Start the duet!. It is the reward colour, so it never sits beside another gold button.
  • Danger (.btn-danger) is new in the system and for grown-ups only: the final confirm of a destructive family-server action. A child never sees it.

Anatomy

  1. LabelBaloo 2 bold, --text-button (20px). A short, happy verb phrase; the accessible name.
  2. Emoji (optional, trailing)Inherits the label size; wrap it in aria-hidden="true" when the words already say it.
  3. BodyPill (--radius-full), 56px tall (--control-height-md), 16 × 32px padding, background --btn-bg.
  4. LipA solid 6px offset shadow in --btn-edge (--lip-rest). Shrinks to 1px while pressed.

Variants

Variants change mood, not size. Pick by how much the action matters on this screen, then keep to one blue (or one gold) per screen.

Sizes

Medium is the default. Extra-large fills the column for the screen's hero action (Let's go! on Welcome, Start the duet!). Small lives inside rows and dialogs: the Grown-Ups Corner, profile cards, the empty-state actions.

Heights --control-height-sm/md/lg; label --font-size-md/xl/2xl. .btn-xl is full width.

States

Pointer and focus states are forced here with data-state; real screens get them from :hover, :focus-visible, :active, disabled and aria-busy.

Both themes

  • Pressed pushes the body down 4px and shrinks the lip to 1px, so the button visibly "clicks". It is the product's signature interaction.
  • Busy keeps the width, hides the label behind a spinner, sets aria-busy="true" and ignores taps. Only grown-up saves to the family server are ever busy; child actions act at once.
  • Disabled is 55% opaque and flattens the lip. Child screens avoid it: a button a child cannot press is confusing. Leave it enabled and let Twinkle explain instead ("Every singer needs a name! 💙").

Responsive behaviour

  • Child screens are one centred column (--layout-screen-max, 470px) at every width, so buttons never rearrange between phone and tablet.
  • .btn-xl and buttons inside a dialog fill their column. Buttons in a .cta-row share the row equally (flex: 1) and keep at least 56px height.
  • In .setting-row and manager rows, small buttons stay on the row; when the row is narrower than its contents the buttons wrap below the label, never shrink their text.
  • Labels never truncate. A label that wraps at 360px is too long: shorten the words, keep the emoji.

Theming

The button reads four component tokens that each variant overrides: --btn-bg, --btn-fg, --btn-edge and --btn-bg-hover. They alias semantic tokens only, so a theme changes the semantic tokens and every button follows.

/* A one-off re-skin without touching .btn */
.holiday .btn { --btn-bg: var(--color-reward-bg); --btn-fg: var(--color-reward-fg); --btn-edge: var(--color-reward-edge); }

In the night studio the blue button lightens to the brand blue (--palette-sky-400) and its label flips to deep navy, keeping 6.6:1. Gold is identical in both themes: sparkles always look like sparkles.

Accessibility

Role and pattern

Native <button type="button">, or <a href> when it navigates (APG Button). Never a <div> with a click handler. No ARIA role is needed.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the button in DOM order.
Enter, SpaceActivates a <button>. Links activate on Enter only.

Focus

The shared ring: 3px --color-focus-ring with a 3px offset, on :focus-visible only. The offset gap shows the surface, so the ring stays at least 3:1 against both the button and the page sky.

Labelling

The visible words are the name. Decorative emoji go in <span aria-hidden="true">. A button that is only an emoji (the pink Sing it again ▶) needs aria-label="Sing London Bridge again".

Motion

Press and lip transition over --duration-fast (120ms), background over --duration-base. Under prefers-reduced-motion the tokens zero these, so the state changes instantly. The busy spinner stops and stays as a ring.

Touch

Every size meets the 52px child target (--target-child) except small (44px), which is only used in grown-up rows with 8px or more between buttons.

Content

  • Short, happy verb phrases a 5-year-old understands: Let's sing!, Keep singing, Sing again, That's me!. Never Submit, OK or Retry.
  • One emoji at the end may add warmth (New song 🎵). Never more than one, and never instead of words.
  • Title case is not used; sentence case with an exclamation only when the action is a celebration.
  • Grown-up destructive labels name the loss: Yes, erase everything, Delete song. The safe choice is a quiet link that keeps things: Keep my stuff.
