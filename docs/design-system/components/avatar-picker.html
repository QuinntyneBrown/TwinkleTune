Avatar picker

A row of big round emoji avatars where one is picked. The picked avatar grows, gets a blue ring and a pink glow, so a five-year-old can see at a glance which one is hers.

WCAG 2.2 AANative <button aria-pressed> in role="group"Status: stableClass .avatar-pick

Overview

Use the avatar picker when a Singer chooses the face that stands for her: on Welcome the first time she opens the app, and in the singer editor when a grown-up adds or edits a Singer on the family server. Exactly one avatar is picked at any moment; there is always a sensible default (🦄 for a new Singer), so the row never asks her to fix an empty choice.

  • Use it only for choosing her own avatar. To show a Singer's face, use an avatar; to filter a list, use chips.
  • Do not use it for more than about twelve choices. The family avatar manager (custom avatars on the server) is a list, not a picker.
  • A photo is an alternative, not another avatar: the singer editor puts a file upload under the row, introduced by its own .pick-label ("…or use a photo 📸").

Anatomy

  1. Group label.pick-label: Baloo 2 bold, --font-size-lg. It names the group (aria-labelledby), so it is real text, not a decoration.
  2. Picked avatarScaled to 112%, border --color-accent, the accent ring --shadow-ring-accent and a pink-to-pale gradient. Selected by aria-pressed="true".
  3. Row.avatars: a centred flex row with a 16px gap (--space-4). .avatars--wrap lets eight avatars wrap in a dialog.
  4. Avatar button.avatar-pick: a 72px disc (--size-avatar-pick), 4px surface border, pale-to-aqua gradient, emoji at --font-size-4xl, --shadow-1.

The button is the same everywhere; the row around it changes with the room it has.

Sizes

The avatar picker has one size: 72px discs, so every choice clears the 52px child target with room to spare.

States

Pointer and focus states are forced here with data-state; real screens get them from :hover, :focus-visible and :active. Picked uses the real attribute, aria-pressed="true".

AvatarDefaultHoverFocusPressedPickedPicked + focusDisabled
Emoji

Both themes

  • Hover grows the disc to 108%; pressed shrinks it to 96%. Together they make the avatar feel like a squeezable toy.
  • Picked is told three ways at once: size (112%), a blue border plus accent ring, and the warmer pink gradient. It never relies on colour alone.
  • Disabled exists only for a grown-up case: an avatar the family server has just removed while the editor was open. Child screens never show a disabled avatar; remove it from the row instead.
  • Picking is instant and local. Nothing is saved until the screen's main button (Let's Sing!, Add singer ⭐, Save) is pressed, so there is no busy state.

Responsive behaviour

  • The column is 470px at every viewport, so the Welcome row of four never rearranges.
  • In a dialog (--layout-dialog-max, 340px) always add .avatars--wrap. Eight avatars then fall into rows centred under each other; the gap stays 16px in both directions.
  • Discs never shrink below 72px to squeeze onto one line. If a row would overflow at 320px without wrapping, it must wrap.
  • Leave at least 8px of free space around the row: the picked avatar grows 6px past its box on every side and must not touch the label or the photo input.

Theming

The picker reads semantic tokens only: --color-bg-surface for the border, --color-decor-pale and --color-decor-aqua for the idle gradient, --color-gentle-bg for the picked gradient, --color-accent and --shadow-ring-accent for the picked edge. It has no component tokens.

In the night studio the decor tints deepen and the surface border darkens with them, so the discs still read as soft pastel buttons against the night canvas; the accent ring lightens to the brand blue so it keeps at least 3:1 against both the disc and the canvas.

/* Re-skin the picked look without touching .avatar-pick */
.holiday .avatar-pick[aria-pressed="true"] { border-color: var(--color-reward-edge); box-shadow: var(--shadow-ring-reward), var(--shadow-1); }

Accessibility

Role and pattern

A role="group" of toggle buttons, labelled by the visible .pick-label; each avatar is a native <button type="button"> with aria-pressed (APG Button, toggle). Pressing one sets it to true and every other to false. A radio group is the stricter alternative; the toggle group is kept because it matches the app and the E2E locators, and because each disc is one Tab stop a child can reach without learning arrow keys.

Keyboard

KeyAction
Tab / Shift+TabMoves through the avatars one by one in DOM order, then on to the next control.
Enter, SpacePicks the focused avatar and un-picks the previous one. Focus stays where it is.

Focus

The shared 3px --color-focus-ring at a 3px offset, drawn as a circle (border-radius: 50%). The offset keeps the focus ring clear of the picked accent ring, so a focused, picked avatar shows both.

Labelling

Every avatar needs an aria-label with the animal's name (Unicorn, Kitten, Frog, Fox, Bunny, Panda, Dino, Octopus). An emoji alone is read differently by every screen reader, and title is not announced reliably. A screen reader then says "Kitten, toggle button, pressed, Pick an avatar, group".

Motion

The grow and shrink transition over --duration-fast (120ms). Under prefers-reduced-motion the duration is zeroed, so the picked avatar jumps straight to its larger size and ring with no tween. The size change itself stays, because it carries the selection.

Touch

72px discs with 16px gaps comfortably exceed the 52px child target (--target-child). The whole disc is the hit area; the emoji is never a smaller target inside it.

Content

  • The group label is a cheerful invitation: Pick your singer! 🌟 on Welcome, Pick an avatar in the grown-up editor. Never Select avatar.
  • Use the eight cast avatars in this order: 🦄 Unicorn, 🐱 Kitten, 🐸 Frog, 🦊 Fox, 🐰 Bunny, 🐼 Panda, 🦖 Dino, 🐙 Octopus. Welcome shows the first four.
  • Avatar names are one friendly word, capitalised, the way a child would say them: Dino, not Dinosaur emoji.
  • No avatar is ever scary, sad or "locked". Every choice is a good one.

// One picked at a time
row.addEventListener('click', (e) => {
  const pick = e.target.closest('.avatar-pick');
  if (!pick || pick.disabled) return;
  row.querySelectorAll('.avatar-pick').forEach((b) => b.setAttribute('aria-pressed', String(b === pick)));
});
