Empty state

Dashed, glassy cards that stand where a list or a reward will be. They never say "nothing"; they say what will appear and the one thing to do next.

Overview

Use an empty state wherever a list, grid or reward area has nothing to show yet. On a child screen an empty space is an invitation: it names what will be there and, when there is something to do, offers one small button. It never reads as a loss, a lock or an error.

The mocks draw it with .new-songs (a dashed card with a big emoji and one sentence), which e2e page objects locate by that class; keep it on child screens. The design system adds .empty-state, the same look with a title slot, for grown-up screens and new places; and .empty-state--compact for a one-line version inside a dialog or row list.

  • First run: nothing earned yet (Sing your first song and it'll shine here!).
  • Empty list: nothing in a set the child cannot fill herself (Grown-ups can add new songs in the Grown-Ups Corner!).
  • No results: a filter hides everything (a difficulty with no songs yet).
  • Server unreachable: a family-server list cannot load, so the card offers solo singing instead. It is an error presented as an empty state, because solo play still works.

Anatomy

  1. Emoji.ico: one emoji at --font-size-3xl (.empty-state: 4xl), aria-hidden. It pictures what will appear (🎁 songs, 🎤 singing, 📡 server).
  2. MessageNunito extrabold, --color-fg-muted, centred. One or two short sentences. .empty-state adds a Baloo 2 <strong> title above it.
  3. Action (optional)One small button in .new-songs-action, 16px below. Only when the child can do something now.
  4. Card3px dashed --color-border-decor edge, --radius-lg, --color-bg-glass-faint, 20px padding. Dashed means "space waiting to be filled".

Responsive behaviour

  • The card fills its container's width and centres its content; the message wraps freely. At 320px the longest mock message (server unreachable) wraps to four lines, which is the limit.
  • Place the card where the content would be (end of the song list, the grid area) so the screen keeps its shape when content arrives.
  • The compact variant switches to a column (centred) below 360px if its text would wrap to more than two lines.

Theming

The card reads --color-border-decor, --color-bg-glass-faint and --color-fg-muted; the title reads --color-fg-default. In the night studio the glass becomes a faint night tint and the dashed edge a night-blue, keeping the "waiting space" feel without glowing. The dashed edge is decoration (D07 keeps it decorative), so no contrast floor applies to it; the text carries the meaning.

Accessibility

Role and pattern

Plain content: a <div> with text and, optionally, a native button or link. No APG widget pattern applies. When an empty state replaces content after a filter change, announce it once through the screen's polite status region (No Brave songs yet), not by making the card itself live.

Keyboard

KeyAction
TabReaches the action, if there is one; the message itself is not focusable.
Enter / SpaceActivates the action (links on Enter only).

Focus

When a filter empties a list, focus stays on the filter chip that was pressed. When a server error swaps a list for this card, focus stays where it was; the card's button is next in tab order.

Labelling

The emoji is aria-hidden; the sentence is the content. The action's label names the whole action (Keep singing solo ▶, not OK).

Motion

The card rises in with the list (.rise); reduced motion shows it at once.

Touch

The action is a small button (44px) in a card with at least 16px around it; on child screens prefer the medium size if it fits.

Content

  • Formula for children: what will appear, then how. Sing your first song and it'll shine here!
  • When the fix is a grown-up's, say so without blame: Grown-ups can add new songs in the Grown-Ups Corner!
  • When the server is away, lead with what still works: You can keep singing with the profile on this device! and offer Keep singing solo ▶.
  • Never No data, Nothing here, Empty, 0 results, You haven't… or a sad emoji.
