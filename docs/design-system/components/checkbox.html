Checkbox

A chunky 24px box with a thick edge and a bold tick, for grown-up choices that are saved with a button. Not in the mocks yet; added for the Grown-Ups Corner and the family-server managers.

Overview

Use a checkbox for an on/off or pick-several choice inside a form that is saved with a button: which songs to share in a duet, which singers' high scores to clear. If the choice takes effect the moment it is tapped, use a switch. If only one answer is allowed, use a radio group.

Not in the mocks yet. Added for the Grown-Ups Corner and the family-server managers (song manager, avatar manager), where a grown-up may act on several rows at once. Children never see a checkbox: on child screens a pick-several choice is a set of chips with aria-pressed.

  • Single: one statement, checked or not.
  • With description: a second line in <small> says what the choice means.
  • Group: several related boxes in a fieldset.form-group with a <legend>.
  • Select all: a parent box that is indeterminate when only some children are checked.

Anatomy

  1. Native inputReal <input type="checkbox">, transparent and 24px, laid exactly over the box so it takes focus, clicks and the accessible state.
  2. Box.check-box: 24px (--space-6), 3px --color-border-strong edge, --radius-sm corners, on --color-bg-surface. Checked fills with --color-accent and draws a tick in --color-fg-on-accent.
  3. LabelBody text (--text-body). The whole <label class="check"> is the hit area, at least 44px tall.
  4. Description (optional)<small> inside the label, --text-body-sm in --color-fg-muted. Part of the name, so keep it short.

Sizes

One size: a 24px box in a row at least 44px tall.

States

Hover and focus forced with data-state on the label. Indeterminate is a script-only property (input.indeterminate = true); this page sets it on load.

Both themes

  • Hover tints the box --color-accent-subtle and turns its edge blue.
  • Checked is a filled blue box and a white tick: shape and fill, never colour alone.
  • Indeterminate is a filled box with a dash. Clicking it checks every child.
  • Invalid is only for a box that must be ticked to continue, such as confirming a family-wide reset. Pair it with a .field-error that says why.
  • Disabled greys the box and the label. Prefer hiding a choice that cannot apply.

Responsive behaviour

  • Boxes stack one per row at every width; never place two checkboxes side by side in the 340px dialog.
  • Long labels wrap under themselves, not under the box (align-items: flex-start keeps the box beside the first line).
  • In a manager row, the checkbox sits at the start of the row and the row text is its label.

Theming

Semantic tokens only. The box is --color-bg-surface with a --color-border-strong edge; checked uses the button's --color-accent and --color-fg-on-accent, so in the night studio it lightens to brand blue with a navy tick, exactly like the blue toy button.

Accessibility

Role and pattern

Native checkbox, so the role, checked and mixed states come for free (APG Checkbox, including the mixed-state example for select all). The visual box is aria-hidden; the input is the control.

Keyboard

KeyAction
Tab / Shift+TabMoves to the next / previous checkbox. Each box is its own tab stop.
SpaceToggles checked. On an indeterminate box, checks it and all its children.

Focus

The shared ring (3px --color-focus-ring, 3px offset) is drawn around the visual box when the hidden input has :focus-visible.

Labelling

The input sits inside its <label>, so the label text, description included, is the name. A group gets a <fieldset> and <legend>; the select-all box lists its children in aria-controls.

Motion

Fill and edge colour fade over --duration-base; reduced motion makes it instant. The tick does not animate.

Touch

The box is 24px (the WCAG minimum), but the whole label row is the target and is at least 44px tall. Keep 8px between rows.

Content

  • Write the label as the thing that will be true when ticked: Offer the tricky part after a song, not Don't hide the tricky part. No negatives.
  • Use the domain words: singer, song, sparkle, tricky part, duet.
  • Sentence case, no full stop, unless the description is a full sentence.
  • Legends are a short noun phrase: Songs in the duet list.

Sources

Not in the mocks yet; added for the Grown-Ups Corner and the family-server managers. Its look is derived from mocks that do exist:

  • dialogs/grown-ups-corner/default (setting rows it would sit in)
  • dialogs/song-manager/default (manager rows a select-all would act on)

Drift rules it follows from the start: control edges in --color-border-strong (D07), focus ring --color-focus-ring (D21), checked fill in the accessible accent rather than brand blue (D01). See the drift log.
