Duet code

The four-letter duet room code, shown as four big letter tiles on the device that made the room and typed into one big field on the device that joins it.

Overview

A duet room is an in-memory room on the family server for exactly two singers, named by a four-letter code. One child taps Make a room ⭐ and sees the code in big tiles; she reads it out, and her duet buddy types it on a second device after Join with a code 🔑. Codes use 23 capital letters with no I, L or O, so they are easy to read aloud and cannot be confused with 1 or 0.

  • Display (.duet-code): four tiles, one letter each, under the ROOM CODE eyebrow in the lobby card.
  • Input (.name-input.code-input): the big name field, restyled for four spaced capitals with an ABCD placeholder.

Duets need the family server. When it is not reachable the Duet screen shows an empty state that offers solo singing instead, and neither part of this component appears.

Anatomy

  1. Eyebrow.duet-eyebrow: ROOM CODE, 12px black caps, letter-spaced, --color-fg-muted.
  2. Letter tile.duet-code span: 56 × 64px (--size-avatar × --size-art), --radius-md, pale-to-aqua gradient, Baloo 2 extrabold at --font-size-4xl. 8px between tiles.
  3. Hint.duet-hint: Tell your duet buddy this code!, then Everyone is here! 🎉 when the buddy joins.
  4. PromptThe visible label: Type the room code 🔑, Baloo 2 at --font-size-2xl (.duet-heading).
  5. Code field.name-input.code-input: 68px field, --color-border-strong 3px edge, centred uppercase Baloo 2 at --font-size-3xl with 0.4em letter spacing.

Sizes

Room codes are always four letters at one size; the tiles and the field are sized to be read across a room.

States

The display has no interactive states. The input follows the shared field states; hover and focus are forced with data-state.

  • Joining: the button goes busy (aria-busy="true") and the field is disabled for the round trip; on success the lobby replaces the card.
  • Invalid sets aria-invalid="true" (border --color-danger-solid) and shows the message under the field with the 💙 marker, and the app also pops it as a pink toast. Focus returns to the field with its text selected so she can retype.
  • Lobby ready: the display stays; the hint changes to Everyone is here! 🎉.

Responsive behaviour

  • Four tiles and three gaps need 248px, which fits inside the lobby card at 320px; tiles never shrink or wrap.
  • The field fills the card and centres its text; at 320px four letters at 0.4em spacing still fit with room for the caret.
  • On phones the on-screen keyboard opens in capitals (autocapitalize="characters"), and the card sits high enough on the screen that Join the duet! stays visible above the keyboard.

Theming

Tiles use the decor gradient --color-decor-pale → --color-decor-aqua with --color-fg-default letters. The field is the shared text field: --color-bg-surface-sunken well, --color-border-strong edge, --color-focus-ring on focus. In the night studio both gradients deepen to night tones and letters lighten, keeping AA.

Accessibility

Role and pattern

The display is one image of text: role="img" with aria-label="Room code K, W, T, M", letters separated by commas so screen readers spell them instead of trying to say "kwitm". (The mock puts aria-label on a plain <div>, where ARIA 1.2 does not allow it to be read; the role fixes that.) The input is a native text field (WAI forms tutorial: labels; no APG widget pattern applies), labelled by the visible prompt with <label for>.

Keyboard

Focus

Opening Join moves focus into the code field so she can type at once. The field's focus is a --color-focus-ring border plus a 2px ring. After an error, focus stays in the field and the text is selected.

Labelling

Visible label Type the room code 🔑; the error is tied with aria-describedby and the field gets aria-invalid="true". The placeholder ABCD is an example, never the label. Use autocomplete="off" and spellcheck="false" so the browser does not "correct" the code.

Motion

The lobby card rises in (.rise). An invalid code may shake the field twice (.shake, --duration-slow); reduced motion removes the shake and keeps the message.

Touch

The field is 68px tall and full width, far above the 52px child target. Tiles are not tappable.

Content

  • Four capitals from ABCDEFGHJKMNPQRSTUVWXYZ. Show them exactly as generated; never add dashes or spaces to the value.
  • Prompts are short and playful: Type the room code 🔑, Tell your duet buddy this code!, Everyone is here! 🎉.
  • Errors say what to do, kindly: That room code wasn't found — check the letters!, That room is already full!. Never Invalid code or Error 404.
