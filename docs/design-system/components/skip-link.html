Skip link

A small white pill that slides into the top-left corner on the first Tab press and jumps straight past the sky decorations to the screen's main content.

Overview

Every TwinkleTune screen starts with a skip link: Skip to content, pointing at <main id="main">. Pointer and touch users never see it. A keyboard or switch user meets it on the first Tab and can jump past the decorative sky (clouds, twinkling stars, drifting notes) and the top bar straight to the screen's one big action.

  • Exactly one per screen, and always the first focusable element in the document.
  • It is not navigation. Moving between screens is the bottom nav and the top bar's back button.
  • The app does not have it yet; the mocks add it (the mocks' README lists it as one of the places "the mocks are a step ahead of the app").

Anatomy

  1. PositionFixed, 12px from the left; parked 80px above the top edge (--space-20) until focused, then 12px from the top. --z-tooltip, above every dialog and toast.
  2. LabelNunito extra-bold, --color-fg-default. Always Skip to content.
  3. Pill--color-bg-surface, --radius-full, 8 × 16px padding, --shadow-1, plus the shared focus ring.

On this page the examples sit inside a stage, so the pill is positioned within the frame rather than the window.

Variants

There is one skip link with one destination, the screen's main element. No screen needs a second skip target.

Sizes

The skip link has one size; it grows with the root font size like everything else.

States

Hidden until focused. The focused state is forced here with data-state="focus"; real screens use :focus.

  • While a dialog is open the skip link must be inert along with the page. In the dialog mocks it sits outside the inert wrapper, so it stays focusable and points at a main that cannot take focus.

Responsive behaviour

  • Same position at every width: top-left of the viewport, not of the 470px column, so it never overlaps the centred top bar's back button on a wide screen.
  • On a narrow phone it overlaps the back button while focused; that is acceptable because the next Tab moves past both.
  • The label never wraps; it is short enough to fit at 320px with 200% zoom.

Theming

Reads --color-bg-surface, --color-fg-default, --shadow-1, --radius-full and the shared focus ring. No component tokens. In the night studio it becomes a night surface pill with light ink, standing out against the dark sky as the white pill does against the day sky.

Accessibility

Role and pattern

A native link to the main landmark, satisfying WCAG 2.4.1 Bypass Blocks. It pairs with the landmarks described in the APG Landmark Regions practice: main for the screen, nav for the bottom nav.

Keyboard

KeyAction
Tab (first press)Focuses the skip link and reveals it.
EnterJumps to #main; focus moves there.
Tab again without activatingHides the link and continues to the first control (usually the top bar's back button).

Focus

The target needs to accept focus: give <main id="main"> tabindex="-1" so browsers move focus, not just scroll. The pill shows the shared 3px --color-focus-ring at a 3px offset.

Labelling

The visible text is the name. Keep it exactly Skip to content on every screen so it is recognisable.

Contrast

Label on the pill
Focus ring against the sky

Motion

It appears in place without a slide. Smooth scrolling to #main follows the page's scroll-behavior, which reduced motion turns off.

Touch

Touch users do not reach it. For switch access its padded pill is at least 44px tall at the default text size.

Content

  • Always Skip to content. Not Skip navigation (there is little to skip on most screens) and not a playful variation: a familiar phrase is more useful than a cute one here.
  • No emoji.
