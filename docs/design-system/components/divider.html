Divider

A divider is a thin, soft line that separates groups when space alone is not enough: sections of the Grown-Ups Corner, an "or" between two ways in, two halves of a toolbar.

Overview

Not in the mocks yet; added for the Grown-Ups Corner, family-server managers and marketing. Child screens separate things with space and with cards (each song is its own white card, each setting its own row), and that is still the first choice. Reach for a divider only when content shares one surface and groups would otherwise blur together.

  • Horizontal (.divider): between groups of rows on one card or dialog, for example On this device settings above Family server settings.
  • Labelled (.divider-label): a rule with a word in the middle, usually or: Make a room ⭐ · or · Join with a code 🔑.
  • Vertical (.divider-vertical): between two clusters in a row, such as filters and a sort control in a grown-up toolbar.

Menus have their own separator (.menu-sep, see Menu), and tables their own row rules (Table).

Anatomy

  1. Rule1px (--border-width-thin) in --color-border-default. Decorative: it does not need 3:1.
  2. Label (labelled only)Overline type, uppercase, --color-fg-muted, 12px gap to each rule.
  3. Spacing16px (--space-4) above and below; vertical dividers take 12px on each side.

Vertical

.divider-vertical stretches to the row's height inside a flex row.

Sizes

Dividers have one weight, 1px; heavier rules read as borders.

States

Dividers are not interactive and have no states.

Responsive behaviour

  • Horizontal and labelled dividers span their container at every width; they never extend into the screen's side margin.
  • When a row with a vertical divider wraps on a phone, drop the vertical divider (hidden below the md breakpoint) rather than leaving a stray line at a row start.
  • Spacing stays 16px at every breakpoint so groups keep the same rhythm on phone and tablet.

Theming

The divider reads --color-border-default and, for the label, --color-fg-muted. In the night studio the border token becomes a navy one step lighter than the surface, so the line stays soft. Both themes are shown below.

Accessibility

Role and pattern

No APG pattern; this is the static WAI-ARIA separator role. A horizontal divider is an <hr>, which already has the role. A labelled or vertical divider built from a <div>/<span> takes role="separator" (and aria-orientation="vertical" when vertical). A purely decorative line between items that are already grouped by headings may be aria-hidden="true" instead.

Keyboard

KeyAction
TabSkips the divider; it is never focusable.

Focus

None. A static separator never takes focus.

Labelling

Give a labelled divider an aria-label matching its visible word, so screen readers announce "or, separator". Do not rely on a divider to convey structure: real groups also get a heading or a <fieldset>.

Contrast

Divider label on a card
Divider label in a dialog

The rule itself is decorative and exempt from 1.4.11; the spacing and headings carry the grouping.

Motion

None.

Touch

Not a target. Keep at least 16px between a divider and the controls on either side so taps never land on the line.

Content

  • A labelled divider holds one short word, almost always or. Never a sentence or a heading.
  • If the groups need names, use headings and leave the line out.
