Select

The browser's own drop-down in the system's sunken well. Children meet one big select, the duet song in the Duet lobby; grown-ups pick difficulty and art style in the song editor.

Overview

Use a select when someone picks one answer from a list too long to show as buttons, and the current answer is already a good one. It is always the native element, so the phone shows its own picker and every assistive technology already knows it.

  • Child select (select.name-input.duet-song) is the one place a child meets a drop-down: Pick the duet song 🎵 in the Duet lobby. The songbook has eight songs or more (seven seed songs, Frère Jacques and any family songs), too many for chips, and Twinkle Twinkle is already chosen, so she can ignore it and press Start the duet!.
  • Grown-up select is Difficulty and Art style in the family-server song editor. The mocks style it with the field class (select.field), which gives the well but no chevron. The system's .select is the same well with a drawn chevron and a 44px minimum height. It is new; prefer it for new work. Both class names stay valid.
  • With five or fewer options, show them all instead: a radio group for grown-ups, chips or big buttons for children, like the difficulty filter on Songs.
  • A custom drop-down (APG Listbox) is out of scope. If native cannot do the job, reconsider the job first.

Anatomy

  1. Label.field-label above, tied with for.
  2. Selected optionBody text (--text-body), 16px, in --color-fg-default. Emoji in the option text are fine and carry meaning only alongside words.
  3. ChevronTwo gradient strokes in --color-fg-muted, 20px from the right edge, drawn in CSS so it follows the theme. Decorative.
  4. Well and edge--color-bg-surface-sunken, 3px --color-border-strong, --radius-md, at least --control-height-sm (44px) tall.

Variants

Standard

The song editor's pair. Art styles are named by what they look like, not Style 1–4.
HTML
<label class="field-label" for="song-difficulty">Difficulty</label>
<select class="select" id="song-difficulty">
  <option value="1" selected>⭐ Easy</option>
  <option value="2">⭐⭐ Medium</option>
  <option value="3">⭐⭐⭐ Brave</option>
</select>

Child select

The Duet lobby: the child field's big well at 18px, with a good song already chosen.
HTML
<label class="duet-song-label" for="duet-song">Pick the duet song 🎵</label>
<select class="name-input duet-song" id="duet-song">
  <option value="twinkle" selected>⭐ Twinkle Twinkle Little Star</option>
  …
</select>

With a prompt option

When there is no sensible default, a disabled first option asks for a choice. Use it only on grown-up forms with required.

Mock markup (still valid)

select.field as the song editor ships it: the well without the drawn chevron or minimum height.

Sizes

.name-input.duet-song on child screens, .select-sm in dense manager rows, .select in dialogs, .select-lg beside a .field-lg.

Both themes

  • Focus on .select uses the shared offset ring (3px --color-focus-ring, 3px gap), because nothing inside shows a caret. The child select keeps the child field's focus edge, since it shares that class.
  • Disabled on the child select is only for the guest's device while the host picks; better still, show the host's choice as text.
  • Invalid only happens with a prompt option left unchosen. Pair the red edge with a .field-error: Pick a song for the duet.

Responsive behaviour

  • Full width of its column; the child select fills the lobby's 360px action column above Start the duet!. In a .field-pair two selects share a row at every width; at 320px each is about 120px, so keep option text under 16 characters.
  • On phones the operating system's wheel or sheet replaces the list; nothing to design.
  • Long option text is cut off by the browser in the closed state. Shorten it rather than widening the dialog.

Theming

Semantic tokens only: --color-bg-surface-sunken, --color-border-strong, --color-fg-default, and --color-fg-muted for the chevron, which is a CSS gradient precisely so it recolours with the theme. The open list is drawn by the operating system; set color-scheme on the theme root so it follows light or dark.

Accessibility

Role and pattern

Native <select> (a combobox with a listbox popup, provided by the browser). If a custom version is ever needed, it must follow APG Listbox inside APG Combobox, and needs an ADR.

Keyboard

KeyAction
Tab / Shift+TabMoves to and from the select.
Space, Enter, Alt+↓Opens the list.
↑ / ↓Moves through options (changes the value directly on some platforms when closed).
Home / EndFirst / last option.
Type a letterJumps to the next option starting with it (option text that starts with an emoji is not reachable this way; see Content).
EscCloses the list without changing the value.

Focus

Shared ring on :focus-visible, at least 3:1 against the dialog surface.

Labelling

Visible <label for>. Changing the value never submits or navigates by itself (WCAG 3.2.2); the song editor applies it on Save.

Contrast

Selected option in the well
Chevron in the well
Edge against the well
Focus ring in a dialog

Motion

None of its own; the operating system animates the open list.

Touch

At least 44px tall in every grown-up size; the child select is about 60px, above the 52px child target.

Content

  • Options are short nouns or adjectives in sentence case. Order them by meaning (Easy, Medium, Brave), not alphabetically.
  • Difficulty's hardest step is Brave, never Hard: it is the same word children see on badges (Brave Bird).
  • Emoji may lead an option for recognition (⭐⭐ Medium) but the word must follow, and must say the whole meaning.
  • Name options by what they are. Style 1…Style 4 tells a grown-up nothing; name the art colour (Aqua, Pink, Sky, Gold).
