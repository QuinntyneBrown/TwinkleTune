Switch

A chunky on/off toggle for a setting that applies the moment it is flipped, like the Grown-Ups Corner's mic timing that saves as it moves. Not in the mocks yet; added for the Grown-Ups Corner.

Overview

Use a switch for a single setting that takes effect immediately, with no Save button: it is a light switch, not a form question. The Grown-Ups Corner already behaves this way (the mic timing offset saves as the slider moves), so its on/off settings are switches.

Not in the mocks yet. Added for the Grown-Ups Corner. If the choice is only applied when a form is saved, use a checkbox. Children never see a switch; a child's on/off is a big toy button or chip with aria-pressed.

  • Label right (input first): the default in stacked lists of settings.
  • In a setting row (label first, switch at the end): matches the Grown-Ups Corner's .setting-row, where the control sits on the right.
  • With description: a <small> line under the label, like the setting rows' If cheers feel late, nudge this.

Anatomy

  1. Track.switch-track: 56 × 32px pill. Off: --color-bg-subtle-hover with a 3px --color-border-strong edge. On: filled --color-accent.
  2. KnobWhite (--color-bg-surface) circle with --shadow-1. Slides right when on, with a little spring (--ease-spring).
  3. LabelBody text naming the setting. The whole label is the target.
  4. Description (optional)<small> in --color-fg-muted.

Variants

Label right

A list of settings, each applied as it flips.
HTML
<label class="switch">
  <input type="checkbox" role="switch" checked>
  <span class="switch-track" aria-hidden="true"></span>
  <span>Count in before each song</span>
</label>

In a setting row

Label first, track at the end of a Grown-Ups Corner row. The input must still sit directly before the track.
HTML
<label class="switch setting-row">
  <span>Offer the tricky part<br><small>Practice one phrase after a song</small></span>
  <input type="checkbox" role="switch" checked>
  <span class="switch-track" aria-hidden="true"></span>
</label>

Sizes

One size: a 56 × 32px track in a row at least 44px tall.

States

Hover and focus forced with data-state on the label.

ValueDefaultHoverFocusDisabled
Off
On

Both themes

  • On vs off differs by knob position and fill, not colour alone: off is a hollow-looking grey track with the knob left; on is filled with the knob right.
  • Disabled is 55% opaque. Use it only when another setting makes this one meaningless, and say why in the description.
  • No invalid or busy state: a switch cannot be wrong, and settings are stored on the device instantly. A setting that saves to the family server should be a checkbox in a form instead, so a failed save has somewhere to be told.

Responsive behaviour

  • The track never shrinks (flex: none); the label wraps instead.
  • In a setting row the label takes the space and the track stays at the row's end at every width, matching the slider and buttons in neighbouring rows.

Theming

Semantic tokens only. Off: --color-bg-subtle-hover track, --color-border-strong edge. On: --color-accent. Knob: --color-bg-surface with --shadow-1. In the night studio the on track lightens to brand blue, as the blue button does.

Accessibility

Role and pattern

A native checkbox with role="switch", so it is announced as "switch, on/off" (APG Switch). The track is aria-hidden.

Keyboard

KeyAction
Tab / Shift+TabMoves to and from the switch.
SpaceToggles on/off and applies the setting at once.

Focus

The shared ring around the track when the hidden input has :focus-visible. Flipping never moves focus.

Labelling

The label names the setting, not the action: Count in, not Turn on count-in. The on/off state is announced by the role; do not add "On"/"Off" text that would contradict it.

Contrast

Off track edge on a card
On track on a card
Knob against the on track
Label in a dialog
Focus ring in a dialog

Motion

The knob slides over --duration-base with --ease-spring, a tiny bounce like the toy buttons; the track colour fades alongside. Reduced motion zeroes the duration, so it jumps.

Touch

The track is 56 × 32px and the whole label row (44px minimum) is the target.

Content

  • Name the setting as a short noun phrase or a positive statement: Count in, Offer the tricky part. No negatives (Don't show…).
  • The description explains what changes for the singer, in one line.
  • Never use a switch for a destructive action (Start everything over is a pink button behind the parent gate).
