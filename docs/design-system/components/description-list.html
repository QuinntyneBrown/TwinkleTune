Description list

Label and value pairs for facts a grown-up checks: a singer's voice range, a song's details, the family server's address. Stacked on phones, side by side on wider screens.

Overview

A description list shows a handful of named facts about one thing: Voice range: B3–E5, Shift: 3 notes higher. Use it when each value needs its label to make sense and there is no comparison across items (that is a table) and no action per line (that is a list).

  • Stacked (.dl) puts each label above its value. The default, and the only layout below 640px.
  • Row (.dl.dl-row) puts labels in a left column and values beside them from 640px; below that it falls back to stacked.

Not in the mocks yet; added for the Grown-Ups Corner and family-server managers, where the mocks currently put the same facts in prose (Your voice goes from B3 to E5 — that's 18 notes!) or in a small note. Children keep the prose version; grown-ups get the list.

Anatomy

  1. Term<dt>, --text-label in --color-fg-muted. A short noun.
  2. Description<dd>, --text-body in --color-fg-default; 12px below each pair when stacked.

Responsive behaviour

  • Below 640px every description list is stacked: label above value, full width.
  • From 640px, .dl-row becomes a two-column grid (max-content labels, values fill the rest) with 16px between columns and 4px between rows.
  • Long values wrap inside their column; labels never wrap mid-word because they are short.

Theming

Reads --color-fg-muted (term), --color-fg-default (description), --text-label and --text-body. It has no surface of its own and inherits the card or dialog behind it, in either theme.

Accessibility

Role and pattern

Native <dl> with alternating <dt> / <dd>. No APG widget applies; screen readers announce it as a description list with term–value pairs (HTML dl). Keep pairs adjacent; do not wrap pairs in extra <div>s unless the grid needs them.

Keyboard

KeyAction
TabSkips the list; stops only on links inside a value.

Focus

Not focusable. Links inside values take the shared ring.

Labelling

Name the list with the heading above it (aria-labelledby on the containing section). Values with emoji (⭐ Easy) keep the word so the emoji can be read or skipped.

Motion

None.

Touch

Not interactive. Links inside values use the quiet link's 44px target height.

Content

  • Terms use the domain words: Voice range, Shift, Streak, Sparkles. Not "Pitch span" or "Transpose".
  • Values carry units in words: 3 notes higher, 4 days, 18 notes.
  • Note names as the app writes them: B3–E5 with an en dash.
