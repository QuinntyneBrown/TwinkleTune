Icon button

Round, white, 52px buttons that hold one emoji: back, pause, settings, edit. They sit at the edges of a screen so the one big action can own the middle.

Overview

Use an icon button for a small, familiar action that one emoji says clearly: Go back (←), Pause (⏸), the Grown-Ups Corner gear (⚙️), Edit Ada (✏️). It is never the screen's main action; that is always a toy button with words. When the action needs words to be understood, use a small button instead.

  • Round (.icon-btn) is the 52px white disc with a soft shadow. It lives in the top bar (back on the left, pause on Sing) and on the Me page (the gear). 134 uses across the mocks.
  • Row (.icon-btn inside .mgr-row, or .profile-edit) shrinks to 40px and drops the shadow: ✏️ and 🗑️ on each Songbook row, ✏️ on each singer's card.
  • Mini (.mini-btn) is a tinted pill for small extras inside a song row: 🏆 for family high scores and 🎤🎤 Duet. It can carry a word next to the emoji.

The blue round play button (.play) on every song is not an icon button: it is the row's main action and is documented with the song row.

Anatomy

  1. GlyphOne emoji at --font-size-2xl (24px), centred. Decorative to assistive technology: the name comes from aria-label.
  2. Disc52 × 52px (--size-control), border-radius: 50%, background --color-bg-surface.
  3. Shadow--shadow-1, a soft blue lift. No lip: icon buttons are quieter than toy buttons.

Variants

Pick the round button for screen-level actions, the row button for actions on one item in a grown-up list, and the mini button for optional extras a child may enjoy but never needs.

Mini buttons

.mini-btn in .song-actions: tinted --color-bg-subtle, label in --color-fg-accent, 8px apart.

Sizes

Size follows context, not a modifier class: the parent decides. The round button is the only size a child taps on her own screens.

Both themes

  • Hover sinks the disc to --color-bg-surface-sunken; the mini button deepens to --color-bg-subtle-hover.
  • Pressed squashes the round button to 90% (scale(.9)), and nudges the mini button down 2px. It feels like squeezing a rubber toy.
  • Disabled is 55% opaque. Only row buttons are ever disabled (a built-in song cannot be deleted while the server is unreachable); hide an action rather than disable it on a child screen.
  • There is no busy state: the action an icon button starts (a dialog, navigation) happens at once, and any wait shows in the dialog it opens.

Responsive behaviour

  • Icon buttons never change size with the viewport. The top bar keeps back on the left, the title centred and a 52px .spacer (or the pause button) on the right at every width.
  • Row buttons keep flex: 0 0 auto, so a long song title wraps rather than squeezing ✏️ and 🗑️.
  • Mini buttons wrap with the rest of .song-meta onto a second line at 360px; they never overflow the row.
  • On a tablet in landscape, the screen column stays 470px wide, so the buttons stay where a child expects them.

Theming

The round button reads --color-bg-surface, --color-bg-surface-sunken (hover), --color-fg-default and --shadow-1; the mini button reads --color-bg-subtle, --color-bg-subtle-hover and --color-fg-accent. There are no component tokens: re-theme through the semantic tokens.

In the night studio the disc becomes the raised navy surface and the shadow deepens, so the button still lifts off the darker canvas (D08). Emoji keep their own colours in both themes, which is why the glyph never carries meaning on its own.

Accessibility

Role and pattern

Native <button type="button">, or <a href> for back, which navigates (APG Button). An icon button that opens a menu adds aria-haspopup="menu" and aria-expanded (see Menu).

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the button in DOM order. Back comes first in the top bar.
Enter, SpaceActivates a <button>. Back (a link) activates on Enter.

Focus

The shared 3px --color-focus-ring ring at a 3px offset, kept round (border-radius: 50%) so it hugs the disc. The mini button uses the same ring around its pill.

Labelling

An emoji is not a name: screen readers read ⏸ as "pause button" on one platform and "double vertical bar" on another. Every icon button carries an aria-label that names the action and, in a list, the item: Edit Ada, Delete Frère Jacques, High scores for Twinkle Twinkle Little Star. The mini Duet button has visible text, but its label still names the song so ten "Duet" buttons are told apart.

Contrast

Glyph and text on the disc
Mini button label on its tint
Row button label on the manager row
Focus ring on the sky

The white disc on the pale sky is below 3:1 by itself; the button's boundary is carried by --shadow-1 and the glyph, which is how WCAG 1.4.11 treats a control whose identifying part is its glyph.

Motion

The squash runs over --duration-fast (120ms). Reduced motion zeroes the duration, so the press shows as an instant change.

Touch

Round buttons meet the 52px child target (--target-child). Row buttons (40px) only appear in grown-up managers and on singer cards, with at least 8px between them. Mini buttons are below the child target (D23): they stay at least 24px tall with 8px between them, and every one is optional, because the play button beside them does the main job.

Content

  • One emoji a 5-year-old already knows: ← back, ⏸ pause, ⚙️ settings, ✏️ edit, 🗑️ delete, 🏆 high scores.
  • The same emoji always means the same action across the app. Never reuse 🗑️ for "clear" or ⚙️ for "options".
  • Labels are short verb phrases plus the thing: Edit Bea, not Edit button or Pencil.
  • A mini button may add one word when the emoji alone is ambiguous (🎤🎤 Duet).
