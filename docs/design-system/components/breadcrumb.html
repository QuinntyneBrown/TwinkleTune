Breadcrumb

A breadcrumb shows a grown-up where they are in a deep page, such as Grown-Ups Corner › Songbook › Frère Jacques, and lets them step back up one level at a time.

WCAG 2.2 AAAPG BreadcrumbStatus: newClass .breadcrumb

Overview

Not in the mocks yet; added for the Grown-Ups Corner on wide screens, the family-server managers and the marketing site. Child screens are never more than one step from Home: they use the top bar's back button and the bottom nav, and never show a breadcrumb.

  • Use a breadcrumb on grown-up pages three or more levels deep, where the back button alone would hide how they got there.
  • It shows the hierarchy, not the history: Grown-Ups Corner › Songbook › Frère Jacques whatever route they took.
  • Do not use it as the only navigation, or on a page that is one level deep.

Anatomy

  1. Ancestor link--text-label (14px extra-bold) in --color-fg-link, underlined, at least 24px tall (--target-min).
  2. SeparatorA "›" drawn by CSS (li + li::before) in --color-fg-subtle, 8px each side. Not read aloud.
  3. Current pagePlain text in --color-fg-default with aria-current="page". Not a link.

  • Hover deepens the link to --color-fg-link-hover; the underline stays.
  • Current drops the underline and turns --color-fg-default: no link, no colour, so it reads as "you are here" without relying on colour.
  • There is no disabled item: every ancestor is reachable.

Responsive behaviour

  • From the md breakpoint up, the full trail shows and wraps onto a second line if it must (flex-wrap), keeping each item whole.
  • Between sm and md, trails of four or more levels keep the first and the last two and fold the middle into "…".
  • Below sm the trail shows only the parent as ← Parent, which is the same job the top bar's back button does on child screens.
  • Item labels never truncate with an ellipsis; a very long song title wraps.

Theming

The breadcrumb reads --color-fg-link, --color-fg-link-hover, --color-fg-subtle (separator), --color-fg-muted (list text) and --color-fg-default (current). No component tokens. The night studio lightens all of them together.

Accessibility

Role and pattern

APG Breadcrumb: a <nav aria-label="Breadcrumb"> landmark around an ordered list. The current item carries aria-current="page". Separators are CSS-generated, so they are not announced.

Keyboard

KeyAction
Tab / Shift+TabMoves through the ancestor links (and the "…" button). The current page is not focusable.
EnterFollows a link.
Enter, SpaceOn "…": expands the folded levels and moves focus to the first of them.

Focus

The shared 3px --color-focus-ring at a 3px offset around each link.

Labelling

One breadcrumb per page, labelled Breadcrumb; if a page ever needs two, give each a distinct label. The "…" button says how many levels it hides (Show 2 more levels).

Motion

None.

Touch

Links are at least 24px tall with 8px plus the separator between them, meeting WCAG 2.5.8. Grown-up pages only.

Content

  • Each item is the page's own title, in the same words: Grown-Ups Corner, Songbook, Singers.
  • The current item is the song or singer name as the family wrote it (Frère Jacques, Mum).
  • No emoji in breadcrumbs; they add noise when read in a row.
  • Start at the Grown-Ups Corner, not at Home: the trail covers the grown-up area only.
